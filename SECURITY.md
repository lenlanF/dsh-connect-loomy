# Privacy and security

- This repository is a **source-only** distribution. It contains no account session, OAuth token, browser cookies, local databases, user profiles, screenshots, or personal machine backup files.
- Credentials are obtained from the local application at runtime and must never be committed.
- DSH host tools are invoked only through the host approval and execution flow; the provider does not grant permissions.
- Do not commit log captures, session state, local config exports, cookies, real phone numbers, or WPS/Loomy access tokens.
